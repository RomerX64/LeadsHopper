# ADR-002: Tenant como workspace comercial

- Estado: aceptada
- Fecha: 2026-09-11

## Decisión

Un tenant representa un equipo comercial y comparte un workspace de Twenty y
una cuenta de Chatwoot entre sus miembros. El usuario no crea un workspace
externo individual.

## Consecuencia

La autorización local y la asociación de usuarios externos son parte del
provisioning. Se evita multiplicar cuentas y se conserva un contexto comercial
común.
