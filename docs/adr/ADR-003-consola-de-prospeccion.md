# ADR-003: LeadHopper como consola de prospección

- Estado: aceptada
- Fecha: 2026-09-11

## Decisión

LeadHopper gestiona zonas, búsquedas, cronjobs, leads, calidad del dato y
operaciones de integración. Twenty mantiene el pipeline y Chatwoot mantiene las
conversaciones.

## Consecuencia

No se implementa un kanban de ventas ni una bandeja de chat propia. El frontend
prioriza una tabla operativa, configuraciones y deep links.
